Quick help

Scan a document

Tap + in the app and scan with the camera. Save the resulting pages as a PDF. To add more pages, open a saved PDF and use the scan/append option.

Organize documents

Use the folder selector to create and browse folders. Swipe right on a PDF to rename or move it, or use Select to move several documents together.

Find a document

Use the search field to find PDFs by filename. Choose All Documents to search the entire collection or choose a folder to search within it.

Back up and restore

Use the ZIP backup option to export your collection, then save the ZIP file somewhere safe using Files or Share. Use Import PDFs from ZIP to restore. Backups created by the app also preserve folder organization and document order.

Reduce a PDF's size

Open a PDF and choose compression. Preview the result before saving a separate copy. Compression may turn pages into images, so searchable text, links, and some PDF features may be lost.

Your documents and backups

PDFs are stored in the app's local storage. Deleting the app can delete those locally stored documents. Before removing the app or changing devices, export a ZIP backup and keep it outside the app.
